# Zomato-Website-HTML-CSS-
* Built a visually appealing Zomato-inspired food delivery website using only HTML and CSS with a fully responsive layout.

* Designed an engaging landing page with modern UI sections including featured restaurants, trending dishes, and food collections.

* Created dynamic restaurant cards with ratings, pricing details, delivery information, and attractive hover animations.

* Developed a stylish search section and location-based interface similar to real-world food delivery platforms.

* Implemented advanced CSS styling techniques such as gradients, transitions, shadows, animations, and responsive grids.

* Focused on delivering a smooth user experience through clean navigation, organized content structure, and mobile-friendly design.

* Enhanced frontend design skills by replicating a real-time food ordering platform interface with pixel-perfect styling.

* Structured the website with reusable components and optimized layouts for readability and performance.

* Practiced modern UI/UX principles including color psychology, spacing consistency, responsive typography, and visual hierarchy.

* Used Visual Studio Code for efficient frontend development, debugging, live preview testing, and project organization.
